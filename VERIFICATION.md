## Unverified

- Firefox does not launch on the developer machine (Windows 11: "side-by-side configuration is incorrect"); firefox is covered only by CI on ubuntu.
- The container smoke has not run locally (no docker on the developer machine); CI only.
- The L6 journey reloads the page, not the server: persistence across a server restart is proven at L3 (process restart) and L7 (container restart), not at L6.
- UI and real-stack suites run on ubuntu only (in the Playwright image); Windows and macOS browsers are not exercised, and there are no win32 or darwin pixel baselines.
- webkit renders at deviceScaleFactor 2 (the Desktop Safari device preset overrides the config's 1); its baseline is 2048x1400. Consistent, but not the same scale as the other engines.
- Upgrading Playwright means changing the pinned @playwright/test version and the image tag together and recapturing tier 3; the guard step fails fast on a mismatch but has not been seen red.
